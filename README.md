# Intervai

Intervai is a mock interview platform where interviewees can book 1:1 sessions with interviewers, join live calls, and get AI-generated feedback after the session.

I built this as a practical full-stack app to combine scheduling, role-based dashboards, real-time video, and AI workflow automation in one place.

## What This Project Does

- Interviewees can browse interviewers by category and book available slots.
- Interviewers can manage availability, see appointments, and track credit earnings.
- Calls are powered by Stream Video (with recording + transcription).
- AI interview questions can be generated by category.
- After a call, Stream webhooks trigger transcript processing and Gemini feedback generation.
- Feedback and recording links are attached back to the booking.

## Tech Stack

- Next.js (App Router)
- React
- Prisma + PostgreSQL
- Clerk (authentication)
- Stream Video / Stream Chat
- Gemini (`@google/generative-ai`)
- Arcjet (rate limiting / protection)
- Tailwind CSS + shadcn/ui

## Local Setup

1. Install dependencies:

```bash
npm install
```

2. Create your environment file (`.env` or `.env.local`) and add required values.

3. Generate Prisma client and run migrations:

```bash
npx prisma generate
npx prisma migrate dev
```

4. Start the dev server:

```bash
npm run dev
```

5. Open:

```text
http://localhost:3000
```

## Required Environment Variables

At minimum, set these for core flows:

```bash
# Database
DATABASE_URL=
DIRECT_URL=

# Clerk
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=

# Stream
NEXT_PUBLIC_STREAM_API_KEY=
STREAM_SECRET_KEY=

# Gemini
GEMINI_API_KEY=

# Arcjet
ARCJET_API_KEY=

# App URL / emails / payouts
NEXT_PUBLIC_APP_URL=
RESEND_API_KEY=
ADMIN_PAYOUT_PASSWORD=
```

## Scripts

- `npm run dev` - run local dev server
- `npm run build` - production build
- `npm run start` - run production build
- `npm run lint` - run ESLint

## Project Structure (Quick View)

- `app/` - routes, pages, layouts, API routes
- `actions/` - server actions (booking, dashboard, AI, etc.)
- `components/` - reusable UI and feature components
- `lib/` - helpers, Prisma client, constants
- `prisma/` - schema and migrations

## Notes

- Stream webhook endpoint is at `app/api/webhooks/stream/route.js`.
- Prisma client is generated into `lib/generated/prisma`.
- This is still an evolving project, so some flows are intentionally iterative.

---

If you are running this locally and something breaks, check env vars first. Most runtime errors in this app are caused by missing keys or misconfigured services.
